# Contributing to Exoplanet 3D Engine

Thank you for your interest in contributing! Here is how you can help improve the project.

## How to Submit Changes

1. **Fork the Repository**: Click the **Fork** button at the top right of this page.

2. **Clone your Fork**:
   ```bash
   git clone [https://github.com/YOUR-USERNAME/exoplanet-3D-engine.git](https://github.com/YOUR-USERNAME/exoplanet-3D-engine.git)
   cd exoplanet-3D-engine

3. **Create a Feature Branch**
   - git checkout -b feature/your-feature-name

4. **Make your Changes**: Make sure your UI works smoothly on both desktop and mobile viewports.

5. **Commit and Push**:
   - git add .
   - git commit -m "Add descriptive summary of changes"
   - git push origin feature/your-feature-name

6. **Open a Pull Request**: Navigate to the original repository and click **New Pull Request** to submit your branch for review.

## Code Style & Guidelines

- Keep CSS mobile-first or properly scoped inside @media queries.
- Ensure event listeners do not block core touch/mouse controls on **.interactive** UI elements.
