# Contributing to Exoplanet 3D Engine

Thank you for your interest in contributing! Here is how you can help improve the project.

## How to Submit Changes

1. **Fork the Repository**: Click the **Fork** button at the top right of this page.
2. **Clone your Fork**:
   ```bash

   cd exoplanet-3D-engine
